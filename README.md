# exospore_seti
This project focuses on planetary protection, aiming to prevent contamination of extraterrestrial environments during space exploration. SEM images of the plates before and after blasting allow for counting the number of bacterial spores transported from one surface to another. Many hundreds of plates are to be imaged, requiring an automated method to count the spores. To automate the analysis, convolutional neural network-based object detection models are trained using the Detectron2 open-source computer vision tool. Model performance is optimized with Ray Tune, and computational resources are provided through Google Cloud. The project combines experimental techniques with advanced machine learning to address critical challenges in planetary protection.
